Sistem Pakar Diagnosa Kerusakan Komputer

# Fitur Utama Program
•	Basis pengetahuan (knowledge base) berisi 6 jenis kerusakan komputer
•	17 gejala yang dapat dipilih pengguna melalui checkbox
•	Mesin inferensi Forward Chaining berbasis Dictionary
•	Menampilkan nama kerusakan dan solusi singkat
•	Menangani kondisi gejala tidak cocok dengan kerusakan manapun
•	Tombol Reset untuk mengulang diagnosa

# Knowledge Base
-	RAM Rusak : Gejala Utama (Blue screen, bunyi beep, RAM tidak terdeteksi)
-	Overheat (CPU Kepanasan) : Gejala Utama (Mati mendadak, sangat panas, kipas berisik)
-	Hardisk Rusak / Corrupt : Gejala Utama (File hilang, bunyi klik, disk tidak terdeteksi)
-	 VGA / GPU Bermasalah : Gejala Utama (Layar Bergaris, resolusi error, artefak visual)
-	PSU (Power Supply) lemah : Tidak menyala, mati-hidup sendiri, bau terbakar
-	OS corrupt: Gagal booting, sering crash, blue screen
